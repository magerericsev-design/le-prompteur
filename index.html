Mes projets

Les projets et images restent dans ce navigateur. Garde une sauvegarde exportée : effacer les données du navigateur peut les supprimer.

Premiers pas

  1. Choisis « Préparer le texte », puis colle ton texte ou importe un fichier .txt en UTF-8.
  2. Sépare les paragraphes par une ligne vide. Une ligne commençant par ## crée un chapitre.
  3. Choisis « Utiliser ce texte », règle la taille et la vitesse, puis appuie sur Lire.
  4. Pause et reprends avec le bouton ou la barre d’espace. Les flèches passent d’un paragraphe à l’autre.
  5. Dans Studio, choisis un passage, ajoute une image et des notes. Contrôle les associations après modification du texte.
  6. Dans Projets, enregistre ton travail et exporte une sauvegarde pour le transférer.

Les textes, images et projets restent sur cet appareil. Les images ne sont pas envoyées à un service distant. Pour ajouter une image : Préparer le texte → Studio → choisir le passage → Référence visuelle. Ferme la fenêtre puis affiche Repères : l’image suit le passage en cours. Une sauvegarde exportée contient aussi les images et les repères à réassocier.
